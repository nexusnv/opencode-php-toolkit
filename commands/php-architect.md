description: Explore a significant PHP architecture decision and wait for approval
---

Use the php-architect design-first workflow for: $ARGUMENTS

Inspect the repository and relevant code paths. Prepare a design note with the goal, constraints, current architecture, 2–3 viable options, trade-offs, affected modules, compatibility or migration concerns, risks, and a focused verification plan. Separate repository evidence from hypotheses and make assumptions explicit.

This command always stops after presenting the recommendation and asks the user to approve or revise the design. Do not edit files, run mutating commands, install dependencies, or create an ADR before approval. Offer an ADR template only for a lasting architecture decision, and create the file only if the user requests it.
